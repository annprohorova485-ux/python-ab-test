# A/B Тестирование: Проблема подглядывания (Peeking Problem)

## Описание задачи
Смоделировать A/B-тест и исследовать, как ежедневный мониторинг p-value влияет на вероятность ошибки I рода (ложноположительного результата).

## Стек
Python, NumPy, SciPy, Matplotlib.

## Что сделано
1. Смоделировано накопление данных за 100 дней для контрольной и тестовой групп.
2. Проведен ежедневный расчет t-критерия Стьюдента.
3. Доказано, что досрочная остановка теста при достижении p-value = 0.05 увеличивает вероятность ложноположительного вывода с 5% до 20-30%.
4. Сформулированы рекомендации по расчету размера выборки до старта теста.
